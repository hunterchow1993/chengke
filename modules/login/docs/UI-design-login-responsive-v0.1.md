## 1. 设计目标

登录页是企业内部系统入口，重点是快速识别品牌、完成认证和理解失败原因。页面不承担营销转化，因此不增加注册、社交登录、轮播、指标或产品截图。

最新版设计使用灰岩蓝而不是原 v3 的高饱和科技蓝，并与后台的侧栏、按钮、输入框、Focus 和状态 Token 保持一致。

## 2. 桌面端

- `≥1280px` 使用左右分屏；品牌区为连续的 `--sidebar` 深色表面，登录区使用 `--header` 或 `--background` 浅色表面。
- 品牌区只保留 Logo、主标题、一句说明、低对比组织关系图形和底部产品定位。
- 组织关系图形使用现有视觉资产，但改为单色低透明度，不使用发光和渐变。
- 登录表单最大宽度 400px，不增加悬浮卡片；通过留白、标题和字段间距建立层级。
- “登录”是唯一主按钮；联系管理员和忘记密码使用次级文字入口。

## 3. 平板端

- 1024-1279px 横向视口保留缩窄分屏，隐藏大型组织图形，避免品牌区内容拥挤。
- 768-1023px 使用单列结构：顶部为紧凑品牌 Header，表单居中并限制为 400px。
- 单列模式不保留大面积深色背景，只使用品牌 Logo 与小面积灰岩蓝强调。

## 4. 移动端

- 页面使用 `min-height: 100dvh` 和自然滚动，内容顺序为品牌、联系管理员、标题、表单、安全提示、页脚。
- 主要内容顶部对齐，避免软键盘弹出时垂直居中算法造成页面跳动。
- 480px 以下左右内边距为 24px；360-479px 为 20px；小于 360px 为 16px。
- 输入框和按钮高 44px；输入文字至少 16px；复选框具有不小于 44px 的可点击区域。
- “7 天内保持登录”和“忘记密码”允许在极窄屏换为两行，但各自触控区域不得重叠。
- 页脚在文档流末尾，不使用 `position: fixed`；底部叠加安全区内边距。

## 5. 表单和状态

- Label 始终可见，Placeholder 只提供输入示例。
- 账号字段使用 UserRound，密码字段使用 LockKeyhole，显示密码使用 Eye / EyeOff。
- 聚焦使用全局 2px Focus Ring；错误文字紧邻字段，不使用 Toast 替代字段错误。
- 登录请求超过 300ms 后按钮显示“登录中”并禁用重复提交。
- 会话过期提示位于标题上方；验证码在密码字段下方渐进出现，不改变其他字段语义。
- 断点和方向变化只改变布局，不重置表单状态。

## 7. 原型验收

- 产品名称准确显示为“澄客 CRM”，不得写成“清客 CRM”。
- 桌面端品牌区使用灰岩深蓝，不出现原 v3 的高饱和亮蓝和发光效果。
- 移动端隐藏完整品牌区，但仍能在首屏识别产品品牌。
- 所有输入具有 Label、图标、边框和明确 Focus 规范。
- 页面只有一个主按钮“登录”，没有注册或第三方登录入口。
- 桌面和移动原型中的文案、字段、保持登录、安全提示和版权信息一致。
