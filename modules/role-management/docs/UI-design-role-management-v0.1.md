## 1. 页面结论

角色管理是独立页面，不与用户管理共用组织树或页内 Tab。列表使用“筛选卡片 + 角色列表卡片”的全宽布局；复杂权限配置在右侧 Drawer 中完成。

## 2. 页面结构

```text
系统管理 / 角色管理
├── 筛选卡片
│   └── 关键词、状态、数据范围、重置、查询
└── 角色列表卡片
    ├── 角色列表 + 新增角色
    ├── 角色表格
    └── 分页
```

- Header 面包屑是唯一页面定位，不重复主标题。
- 筛选卡片和列表卡片垂直间距 16px。
- 列表头左侧显示“角色列表”和结果总数，右侧显示新增、刷新和表格设置。齿轮只控制表格列显隐，不作为角色权限设置入口。
- 不使用组织树，因为角色是权限配置对象，不隶属于单一部门节点。

## 3. 表格层级

- 列顺序：角色名称、角色编码、用户数、数据范围、状态、最近更新、操作。
- 角色名称为主信息，内置角色使用中性小标签补充说明。
- 用户数可点击进入编辑 Drawer 的“角色成员”页签。
- 角色编码和时间使用等宽数字字体。
- “编辑”为常驻操作；权限设置、成员管理、启停和删除收纳在更多菜单。“权限设置”打开同一编辑 Drawer 并直接定位功能权限页签。
- 删除属于危险操作，只在满足业务条件时出现，并使用二次确认。

## 4. 编辑 Drawer

- 桌面宽度 720px，Header 和 Footer 固定，中间区域独立滚动。
- 页签顺序：基本信息、功能权限、数据权限、敏感字段权限、角色成员。
- Footer 始终显示取消和保存；有未保存修改时关闭需要确认。
- 页签顶部可展示错误数量；保存校验失败后自动定位第一个错误页签。

### 4.1 功能权限树

- 树节点最小高 40px，复选框、展开箭头和名称点击区域清楚分离。
- 工具区提供关键词、展开全部、收起全部、全选和清空。
- 半选状态必须可见；取消父节点导致大量权限减少时，在保存前展示差异摘要。
- 目录、页面和操作使用同一棵资源树表达；勾选操作时自动补齐所属页面和必要祖先。
- 页面下的操作作为末级节点展示；取消页面会同时取消所属操作并展示影响摘要。

### 4.2 数据权限

- 五种数据范围使用单选卡片纵向排列，每项包含名称和一句明确范围说明。
- 选择“指定部门”后出现可搜索组织树和已选部门摘要。
- “包含下级部门”使用每个已选部门旁的 Switch，避免一个全局开关造成歧义。
- 扩大到全集团或明显扩大部门范围时使用警告确认，不使用常驻大面积红色。

### 4.3 敏感字段权限

- 按业务模块分组展示字段权限，每项说明未授权时的脱敏结果。
- 未授权所属页面时，对应字段权限不可选择并说明原因。
- 新增完整手机号、邮箱或联系方式权限时纳入扩权确认，不使用常驻警告色。

### 4.4 角色成员

- 使用紧凑筛选和成员表格，支持添加、移除与批量调整。
- 单角色替换确认同时展示用户、原角色和新角色。
- 成员数量较多时使用服务端分页，不在 Drawer 一次性加载全部成员。

## 5. 响应式

| 内容宽度 | 页面规则 |
| --- | --- |
| ≥1200px | 筛选单行，展示全部核心表格列，Drawer 720px |
| 1024–1199px | 筛选允许两行，隐藏低优先级更新时间，Drawer 最大占 70vw |
| <1024px | 表格受控横向滚动，Drawer 占满可用宽度；非一期移动端核心场景 |

## 6. 一致性要求

- 颜色、字体、间距、圆角、阴影、状态色和 Icon 只引用全局 `MASTER`。
- 图标统一使用 Lucide，不使用 Emoji、混合图标库或无 Tooltip 的纯图标按钮。
- 正常状态使用成功语义，已停用使用中性色，高风险删除只在确认阶段使用错误语义。
- 用户管理和角色管理的筛选卡片、列表卡片、表格、分页与 Drawer 视觉语言保持一致。

## 7. 设计验收

- 页面一眼可识别为角色列表，不出现组织树或用户管理标题。
- 筛选、列表、抽屉三层任务边界清楚。
- 功能权限、数据范围、敏感字段权限和成员调整均能解释结果及风险。
- 页面没有依赖颜色才能理解的状态，也没有被裁切的核心操作。
