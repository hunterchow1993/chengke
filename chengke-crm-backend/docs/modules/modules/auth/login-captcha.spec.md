## 1. 接口概述

- **用途与调用场景**：风控要求验证码时，登录页展示或刷新验证码图片；服务端签发 `captchaToken`（登录 PRD §6.2、§8.3「刷新验证码」）。
- **功能权限 / 数据权限**：无业务权限码；**公开接口**（总览 §8.1）。须进入认证白名单。
- **成功状态码**：**待确认**；设计建议 HTTP 200。
- **是否修改数据**：不改变用户账号数据。会**新增**一条验证码挑战（总览 §6.4、§7.3）。对登录会话无创建 / 撤销。
- **引用章节清单**：
  - 总览 §4.2（验证码规则：4–6 位、不区分大小写、60 秒、一次使用）
  - 总览 §5.3 风控与验证码、§5.7 安全（响应不得含密码）
  - 总览 §6.4 验证码挑战状态
  - 总览 §10.2 重复拉取、§11.2 错误码、§14 缓存（不新增账号缓存）

## 4. 参数校验与业务校验

**参数校验**：无已确认必填业务字段。

**业务校验**：

- 本接口**不**要求调用方已经触发「需要验证码」；PRD 允许在需要时拉取 / 刷新。是否允许未达阈值的客户端任意刷图 **待确认**（可能被用来压测或枚举）。
- 系统不可用时不得返回可猜测的固定验证码。

## 5. 业务逻辑（Service 层）

```text
请求获取验证码
↓
（可选）IP / 全局限流 → 超过则 RATE_LIMITED（是否适用本接口待确认）
↓
生成 4–6 位验证码（大小写不敏感的比对规则在登录校验时生效）
↓
签发 captchaToken；挑战 60 秒后失效；一次使用后失效（登录 PRD §6.2）
↓
持久化挑战（介质待确认）
↓
返回图片与 token（响应形态待确认，总览 §18 P1-4）
```

| 条件 | 是否允许 | 系统行为 |
| --- | --- | --- |
| 正常签发 | 是 | 新挑战有效 60 秒 |
| 重复拉取 | 是 | 每次新挑战；旧 token 是否立即失效 **待确认**（总览 §10.1） |
| 系统异常 | 否 | `SYSTEM_UNAVAILABLE`；不留下永不过期的挑战 |

验证码字符集（仅数字 / 含字母）PRD 未规定 → **待确认**。

## 7. 响应结构

PRD 确认存在：`captchaToken`（服务端签发）、验证码**图片**、60 秒失效。未确认：图片是二进制还是 JSON 内嵌、token 在 Body 还是 Header。

| 字段 | 类型 | 是否必定存在 | 空值规则 | 业务含义 | 来源 |
| --- | --- | --- | --- | --- | --- |
| `captchaToken` | string | 是（业务上必须能交给登录请求） | 非空 | 登录提交时回传 | 服务端签发 |
| 验证码图片 | **待确认** | 是 | — | 用户识别后填入 `captchaCode` | 服务端生成 |
| 过期秒数或过期时间 | **待确认** | PRD 未要求返回 | — | 前端也可按 60 秒本地计时 | 不得编造字段名 |

不得返回正确 `captchaCode` 明文。不得返回密码或会话凭证。

## 9. 成功 / 失败行为

**成功**：新挑战已签发且 60 秒内可用一次 → 调用方展示图片。不改变用户与会话。

**失败**

| 场景 | 数据是否变化 | 错误码 | 业务是否终止 |
| --- | --- | --- | --- |
| 限流（若启用） | 否或仅审计 **待确认** | `RATE_LIMITED` | 是 |
| 系统异常 | 不得留下不过期挑战 | `SYSTEM_UNAVAILABLE` | 是 |

登录使用阶段的 `CAPTCHA_INVALID` / `CAPTCHA_REQUIRED` 属于 [login.spec.md](./login.spec.md)，本接口不返回这两码，除非评审决定获取失败也用同类码。

---

## 10. 事务与并发要点

- 无用户行事务。挑战存储失败则接口失败，不得告诉前端「已有 token」却无法校验。
- 并发多次 GET：总览 §10.1，多 token 是否同时有效 **待确认**。
- 与登录校验的一次性作废必须一致（总览 §6.4）。

---

## 11. 验收标准（本 API）

- [ ] 匿名可调用（白名单）。
- [ ] 签发的 token 可在 60 秒内被登录接口一次性使用。
- [ ] 过期或使用过后，登录侧表现为 `CAPTCHA_INVALID`。
- [ ] 响应不含验证码正确答案、密码或会话凭证。
- [ ] 比对不区分大小写（在登录校验中验证，本接口生成须与该规则兼容）。
